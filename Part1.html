Section 1: Convolution & Implementation Methods

Let’s begin by first discussing what a convolution is and look at different ways to implement and how each method effects the processing time and results. Convolution is a way to scan every pixel in an image and extract useful information from it or transform its features to make them more meaningful. Convolution uses a kernel or a filter to process pixels in the context of its neighboring pixels.

The most fundamental way to implement a convolution is by using array functions and for loops. This method helps new users to understand how convolution works. Having this understanding is crucial to further perform useful image processing operations using filters and convolution.


                        #part 1.1: Convolution with 4 for loops
                        import numpy as np
                        import matplotlib.pyplot as plt
                        import cv2
                        
                        img = cv2.imread(r"C:\Users\Muhammad Muneeb\Desktop\Documents\Masters\SYDE 671\Assignment 2\Me.jpeg")
                        img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
                        
                        kernel = np.ones((9, 9), dtype=np.float32) / 81.0

                        def convolve_with_4forloops(img, kernel):
                            kernel_h, kernel_w = kernel.shape
                            img_h, img_w = img.shape
                        
                            pad_h = kernel_h // 2
                            pad_w = kernel_w // 2
                        
                            padded_img = np.pad(img, ((pad_h, pad_h), (pad_w, pad_w)), mode = 'constant', constant_values = 0)
                        
                            flip_kernel = np.flip(np.flip(kernel, axis = 0), axis = 1)
                        
                            output = np.zeros_like(img, dtype=np.float32)
                        
                            for i in range(img_h):
                                for j in range(img_w):
                                    pixel_sum = 0.0
                        
                                    for k in range(kernel_h):
                                        for l in range(kernel_w):
                                            img_val = padded_img[i + k, j + l]
                                            kernel_val = flip_kernel[k, l]
                                            pixel_sum += img_val * kernel_val
                        
                                    output[i, j] = pixel_sum
                                    
                            return output
                        
                        result = convolve_with_4forloops(img, kernel)
                        plt.figure(figsize=(10,5))

                        plt.subplot(1, 2, 1)
                        plt.title('Original Greyscale')
                        plt.imshow(img, cmap = 'gray')
                        plt.axis('off')
                        
                        plt.subplot(1, 2, 2)
                        plt.title('Filtered (Blurred)')
                        plt.imshow(result, cmap='gray')
                        plt.axis('off')
                        
                        plt.show()

After loading in the required libraries, NumPy to use array functions and matplotlib to plot our images we load in the image and convert it from color to grayscale. Once the image is loaded, we define our kernel; a 9x9 matrix of ones. This is a box filter that will reduce the sharpness and make it smooth. Simply put it makes the image blurred. Next we define our convolution function, we start by padding the image all around with zeros to make sure that the edge features don’t get deleted during the convolution operations as the kernel moves across the image. Next, we define our four nested for loops. The outer loops iterate over the image size (height and width) and the inner loops iterate over the kernel size and perform the dot product over a size of the image equal to the kernel size across the entire image. The results of the convolution are stored in an array and returned at the function call. Below are the results of the convolution performed with the above code.

The following code uses only two for loops instead of four to achieve the same effect as before. 


                        #part 1.1: Convolution with 2 for loops
                        import numpy as np
                        import matplotlib.pyplot as plt
                        import cv2
                        
                        img = cv2.imread(r"C:\Users\Muhammad Muneeb\Desktop\Documents\Masters\SYDE 671\Assignment 2\Me.jpeg")
                        img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
                        
                        kernel = np.ones((9, 9), dtype=np.float32) / 81.0
                        
                        def convolve_with_2forloops(img, kernel):
                            kernel_h, kernel_w = kernel.shape
                            img_h, img_w = img.shape
                        
                            pad_h = kernel_h // 2
                            pad_w = kernel_w // 2
                        
                            padded_img = np.pad(img, ((pad_h, pad_h), (pad_w, pad_w)), mode = 'constant', constant_values = 0)
                        
                            flip_kernel = np.flip(np.flip(kernel, axis = 0), axis = 1)
                        
                            output = np.zeros_like(img, dtype=np.float32)
                        
                            for i in range(img_h):
                                for j in range(img_w):
                                    roi = padded_img[i : i + kernel_h, j : j + kernel_w]
                                    output[i, j] = np.sum(roi * flip_kernel)
                                    
                            return output
                        
                        result = convolve_with_2forloops(img, kernel)
                        plt.figure(figsize=(10,5))
                        
                        plt.subplot(1, 2, 1)
                        plt.title('Original Greyscale')
                        plt.imshow(img, cmap = 'gray')
                        plt.axis('off')
                        
                        plt.subplot(1, 2, 2)
                        plt.title('Filtered (Blurred)')
                        plt.imshow(result, cmap='gray')
                        plt.axis('off')
                        
                        plt.show()

This time we used two for loops instead of four. Instead of iterating over the entire image, this time around we pick a region of interest matching the size of our kernel, perform the convolution calculation and then slide our region of interest one column to the right and repeat for the entire image. Below is the result of this code and you can see the results are identical however the processing time is significantly reduced and larger images can be processed more effeciently with this code.

Section 2: Edge Detection Using Difference Operators

Now we will look at another useful way to process images and extract useful information. We are going to look at how to detect the edges of an image using the difference operators. Difference operators are uni-directional vectors that are used to extract magnitudes in the y and x directions. The dy operator works by subtracting the pixel above from the pixel below, this highlights the vertical edges as the operator moves across the image rows from top to bottom. The dx operator works in the same way but in the horizontal direction, capturing the magnitudes of the edges across the image from left to right.

The code below uses the built-in convolve function and dx and dy difference operators to capture the edges of an input image. The convolution function takes care of the padding and also makes sure that output image is the same size as the original image.


                        #part 1.1: Convolution with scipy

We will now take a deeper dive into difference operators and see the individual gradients in the x and y directions along with the magnitude. The gradient is calculated by convolving the image with an x and y difference operator respectively and calculating the sum of the square roots of the gradients in dx and dy. The following code is used to calculate the gradients. 


                        #1.2 Finite diference operator
                        import numpy as np
                        import matplotlib.pyplot as plt
                        import cv2
                        from scipy.signal import convolve2d
                        
                        img = cv2.imread(r'C:\Users\Muhammad Muneeb\Desktop\Documents\Masters\SYDE 671\Assignment 2\hybrid\cameraman.jpeg')
                        img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
                        
                        dx = [[1, 0, -1]]
                        dy = [[1],
                              [0],
                              [-1]
                             ]
                        
                        grad_x = convolve2d(img, dx, mode='same', boundary='fill', fillvalue=0)
                        grad_y = convolve2d(img, dy, mode='same', boundary='fill', fillvalue=0)
                        grad_mag = np.sqrt(grad_x**2 + grad_y**2)
                        
                        plt.figure(figsize = (5, 5))
                        plt.subplot(2, 2, 1)
                        plt.title('Original Greyscale')
                        plt.imshow(img)
                        plt.axis('off')
                        
                        plt.subplot(2, 2, 2)
                        plt.title('Partial derivative dx')
                        plt.imshow(grad_x)
                        plt.axis('off')
                        
                        plt.subplot(2, 2, 3)
                        plt.title('Partial derivative dy')
                        plt.imshow(grad_y)
                        plt.axis('off')
                        
                        plt.subplot(2, 2, 4)
                        plt.title('magnitude of dx and dy')
                        plt.imshow(grad_mag)
                        plt.axis('off')
                        
                        
                        threshold = [20, 30, 40, 50, 60, 70, 80, 90]
                        
                        plt.figure(figsize= (16, 8))
                        for i, j in enumerate (threshold, start=1):
                            binarized_grad_mag = (grad_mag >= j) * 255
                        
                            plt.subplot(2, 4, i)
                            plt.title(f'Threshold: {j}')
                            plt.imshow(binarized_grad_mag)
                            plt.axis('off')
                        
                        plt.show()

Section 3: Derivative of Gaussian (DoG) Filter

Enhancing edges reliably requires smoothing the image first to remove high-frequency noise before applying difference operators[cite: 1].

We compared two approaches: a two-step approach (blurring the image first, then applying $dx$/$dy$) versus a single-step DoG approach (convolving the original image directly with pre-computed DoG filters). While both produce nearly identical results, the single-step method eliminates intermediate calculations, saving computational overhead on larger images like the Nutmeg cat image (300 KB)[cite: 1].

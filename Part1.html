Section 1: Convolution & Implementation Methods

Let’s begin by first discussing what a convolution is and look at different ways to implement and how each method effects the processing time and results. Convolution is a way to scan every pixel in an image and extract useful information from it or transform its features to make them more meaningful. Convolution uses a kernel or a filter to process pixels in the context of its neighboring pixels.

1. Four For-Loops Implementation: The most fundamental way to implement a convolution is by using array functions and for loops. This method helps new users to understand how convolution works. Having this understanding is crucial to further perform useful image processing operations using filters and convolution.

Section 2: Edge Detection Using Difference Operators

Difference operators ($dx$ and $dy$) are uni-directional vectors used to extract gradient magnitudes horizontally and vertically[cite: 1].

The partial derivative $dy$ highlights vertical edges by subtracting the pixel above from the pixel below, while $dx$ captures horizontal edges[cite: 1]. The combined gradient magnitude is calculated as $\text{grad\_mag} = \sqrt{\text{grad\_x}^2 + \text{grad\_y}^2}$[cite: 1].

Threshold Sweeps: To suppress background noise (such as grass or minor textures), binarization loops apply intensity cutoffs. Pixels above the threshold are set to 255, while those below are set to 0. Finding the optimal threshold requires balancing feature clarity against background loss[cite: 1].

Section 3: Derivative of Gaussian (DoG) Filter

Enhancing edges reliably requires smoothing the image first to remove high-frequency noise before applying difference operators[cite: 1].

We compared two approaches: a two-step approach (blurring the image first, then applying $dx$/$dy$) versus a single-step DoG approach (convolving the original image directly with pre-computed DoG filters). While both produce nearly identical results, the single-step method eliminates intermediate calculations, saving computational overhead on larger images like the Nutmeg cat image (300 KB)[cite: 1].
